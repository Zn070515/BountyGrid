## 4. 测试与自动化边界（平台级）

- 所有项目默认**禁止可能导致目标网络/主机/设备瘫痪的大流量、大线程、大规模扫描**；否则可能被视为攻击并承担法律责任。
- **默认禁止内网挖掘**；仅攻防类项目在项目明确授权时可进一步内网渗透。
- **不得造成拒绝服务或业务影响**；敏感操作前必须联系项目管理员。
- VPN：项目要求时必须用 VPN（流量审计/IP白名单），否则漏洞可能无效或被视攻击。
- webshell：平台通用评定原则禁止获取权限后下载源码审计（需厂商同意）；**联想SRC明确禁止上传webshell**（冻结未提奖金+拉黑）。
- 数据：SQL注入须注出一条数据证明，严禁拖库；严重敏感身份信息至少3个敏感字段。
- 重复：同一漏洞源多个漏洞按1个计；重复无积分。

## 6. 奖励与提现

- 奖励类型：现金、金币、荣誉（Rank+积分）；闪测另有碎银/红包/京东卡。
- 现金：高级项目由厂商委托平台发放；公益SRC由平台发放。
- 重复漏洞无积分；先到先得是奖励重要依据。
- 段位：传说/钻石/黄金/白银/青铜；赛季积分清零，总积分累计。
- 提现：
  - 必须绑定本人银行卡；
  - 每次最低 **300元**；每年 **6月、12月无最低金额**；
  - 申请后 **次月10-15日** 打款；

- 提成金：仅众测项目；企业SRC/小包/活动/重复/白帽保护不发放；次月1日或漏洞关闭后发放。

```json
{
  "platform": "vulbox",
  "preferred_data_source": ["AUTHENTICATED_WEB", "BROWSER_AUTOMATION", "MANUAL_IMPORT", "PUBLIC_WEB"],
  "authentication_mode": "微信扫码/手机验证码/账号密码，浏览器 Cookie",
  "browser_required": true,
  "api_available": false,
  "manual_fields_required": ["加入项目", "高级项目申请", "NDA签署", "银行卡绑定", "报告提交"],
  "sync_frequency": "项目状态 15-60min（会发生暂停/重开）；公告 6h；账号/财务 1d",
  "high_risk_operations": ["加入项目", "提交漏洞", "提现", "绑定银行卡", "签署NDA"],
  "human_only_operations": ["加入/申请项目", "签署NDA", "提交报告", "提现", "绑定收款"]
}
```

- 自动化等级：**LEVEL 2**（可读取项目/规则/状态；项目加入、NDA、报告提交必须人工）。
- 建模重点：
  - 项目按 `enterprise_src / advanced / ordinary / flash / offensive / offline / exclusive` 分类；
  - `eligibility` 要区分“已加入可直接提交”“需申请审核”“需NDA”“已暂停/结束”；
  - 高级项目选择是**软门槛**（信誉/排名/历史/技能/资料/顺序），不是单一数值阈值；
  - 项目状态会频繁暂停/重开，缓存时间必须短；
  - 提现前必须完成银行卡绑定，且最低300元（6/12月例外）。
